# iBroadcast integration for Onyx

## Goal

Add an optional **Music / iBroadcast** source to an Onyx user profile without mixing iBroadcast credentials, history, playlists, or preferences between Onyx users.

## Implemented architecture

The integration is deliberately compartmentalized from Movies and TV:

```text
src-tauri/src/ibroadcast.rs
src-tauri/src/ibroadcast_oauth.rs
src/components/IbroadcastConnect.tsx
src/components/IbroadcastLogoKit.tsx
src/components/MusicView.tsx
providers/ibroadcast/<onyx-user>/library.json
```

Removing or disabling the provider does not alter the local video library database.

## Authentication

Onyx uses iBroadcast OAuth 2.0 **Authorization Code + PKCE** for the desktop/server application.

Onyx opens the user's normal browser for authorization, starts a temporary localhost callback listener, validates OAuth `state`, exchanges the authorization code with the PKCE verifier, and stores the resulting access/refresh tokens in the operating-system credential store. Browser clients never receive those tokens.

The callback listener only exists while an authorization attempt is active and shuts down after the callback or after a five-minute timeout.

### Required Redirect URI

Configure the iBroadcast developer application with this exact Redirect URI:

```text
http://127.0.0.1:8770/oauth/ibroadcast/callback
```

The iBroadcast developer app **Grant Type must be Authorization Code**.

Onyx does not require the generated iBroadcast Client Secret for the PKCE flow. Do not paste the Client Secret into Onyx or commit it to the repository.

## Creating an Onyx developer app in iBroadcast

iBroadcast requires a **128 × 128 PNG** image for a developer application.

1. Sign in to the iBroadcast web player.
2. Open **Apps → developer**.
3. Create a new developer application named **Onyx**.
4. Set **Grant Type** to **Authorization Code**.
5. Set **Redirect URI** exactly to:

   ```text
   http://127.0.0.1:8770/oauth/ibroadcast/callback
   ```

6. In Onyx, open **Settings → Music** or the iBroadcast step of first-run setup.
7. Choose **Save 128×128 PNG**.
8. In the desktop client, choose the save location in the native Save dialog. Onyx confirms the exact path after the file is written. In a browser, the browser's normal configured download location is used.
9. Upload that PNG to the iBroadcast developer application.
10. Save the application and copy its **Client ID**.
11. Paste the Client ID into Onyx and save it.
12. Select the Onyx profile that should own the music connection and choose **Connect**.
13. Onyx opens the iBroadcast authorization page in the system browser.
14. Sign in and approve access.
15. iBroadcast redirects the browser to Onyx's temporary localhost callback.
16. Return to Onyx. The profile should show as connected and the first library sync will begin.

The logo is generated by Onyx at exactly **128 × 128 pixels** rather than relying on a checked-in image file. The preview and saved PNG therefore come from the same generated image.

The iBroadcast **Client ID is server-wide**, while OAuth account connections, tokens, and cached library state are **per Onyx profile**. Never commit access tokens or refresh tokens to the repository.

## Library

The provider library is fetched from iBroadcast and normalized into Onyx-specific music models:

```text
Artist
  Album
    Track
Playlist
```

Onyx caches normalized metadata, not the user's audio files.

The Music interface supports finding music by:

- artist
- album
- artist + album
- track
- playlist

## Playback

Audio is proxied through the authenticated Onyx server:

```text
Onyx client
    ↓
Onyx Rust server
    ↓
iBroadcast streaming service
```

This keeps OAuth credentials and provider stream construction out of the browser.

## Security boundary

The browser never receives an iBroadcast refresh token or stored OAuth credential. OAuth exchange, refresh, library calls, and stream lookup occur in Rust.

PKCE uses a one-time verifier/challenge pair and OAuth `state` is checked on callback to prevent a callback from being accepted for the wrong authorization attempt.
